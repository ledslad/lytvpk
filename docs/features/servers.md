# 收藏服务器

“收藏服务器”用于保存常用 L4D2 服务器，查看状态并快速连接。

## 麻衣安全屋

侧栏“麻衣安全屋”提供成都 `cd.fastbot.top` 与广东 `gd.fastbot.top` 两个预设，显示人数、当前地图与在线状态。页面可见时每 30 秒刷新一次；查询失败会显示失败状态，不把上次在线结果继续当成实时状态。

点击“加入服务器”可直接加入。两服状态与地图同步集中在此页；“收藏服务器”和启动菜单沿用原有收藏与最近连接功能。

地图同步默认使用成都服。可在本页“同步来源”中填写服务器域名或 HTTPS 地址并保存，也可通过“设置 → 网络设置 → 服务器地图同步”修改。

1. 先在 MOD 管理页选择本机 `addons` 目录。
2. 在“麻衣安全屋”点击“预览变更”，查看待下载、待清理及需手动处理的地图。
3. 点击“同步地图”，将缺图加入本机下载队列。提交任务不等于下载完成，请在“查看下载任务”中核对结果。
4. 默认同时清理服务器明确删除的旧图；可取消此选项，只补齐缺图。旧地图及元数据、封面移入 `addons/disabled/server-sync-*`，可点击“恢复上次清理”还原，不会覆盖同名现有文件。
5. 不再需要备份时，点击“清空回收站”，核对数量、占用空间和目录后确认永久删除。只处理当前 addons 目录中有有效恢复记录的地图同步备份，其他禁用 MOD 不受影响；异常记录、未记录文件、链接或子目录会使对应批次保留。下载进行中禁止清空，确认期间目录或备份内容变化时需重新确认。清空后无法恢复。

清理只接受成功且无错误的明确删除记录，并保留服务器当前清单中的地图与依赖。查询失败、分页不完整、快照发生变化或限流时会停止清理。不会因“不在服务器清单”而删除本机地图，也不会连带清理其他 MOD 或 `workshop` 子目录。

## 添加服务器

点击“添加服务器”，填写：

- 名称：自己容易识别的名字。
- 地址：服务器 IP 或域名，例如 `127.0.0.1` 或 `example.com:27016`。端口可选，未填写时默认使用 `27015`。
- 权重：用于排序，数值越大越靠前。

保存后，服务器会显示在列表中。

### 通过 LytVPK 协议添加

网页或其他应用可以通过以下协议链接直接添加收藏服务器：

```text
lytvpk://favoriteServer/{服务器名}/{服务器地址}
```

例如：

```text
lytvpk://favoriteServer/%E6%B5%8B%E8%AF%95%E6%9C%8D%E5%8A%A1%E5%99%A8/127.0.0.1
```

服务器名和地址必须分别进行 URL 路径编码。生成链接时可以使用：

```js
const url = `lytvpk://favoriteServer/${encodeURIComponent(name)}/${encodeURIComponent(address)}`;
```

服务器地址可以省略端口，此时会自动使用 `27015`。重复打开同一地址的链接不会重复添加。

## 查看状态

列表会查询服务器状态，并显示：

- 服务器名称。
- 游戏模式。
- 当前地图。
- 在线人数。

点击刷新可以重新查询。双击服务器可以查看详情和玩家列表。

## 连接服务器

点击“连接”会启动 L4D2 并连接到对应服务器。

主侧边栏底部的启动按钮会记录最近连接的服务器，方便下次快速进入。

## IP 直连

如果只想临时进入某个服务器，不需要收藏，可以点击工具栏的“IP 直连”，在唯一的地址输入框中填写服务器地址：

- `127.0.0.1`：不写端口时默认使用 `27015`。
- `127.0.0.1:27015`：IP 或域名与端口之间用 `:` 拼接。
- `[::1]:27015`：IPv6 地址使用方括号。

也可以直接粘贴控制台命令或 Steam 链接，会自动识别并去掉前缀：

- `connect 127.0.0.1:27015`
- `steam://connect/127.0.0.1:27015`

打开弹窗时会自动读取剪贴板：如果剪贴板里看起来就是服务器地址，会直接填入并选中，省去手动粘贴。判定比较严格，只有以下内容会被自动填入：

- IPv4、IPv6 地址，例如 `127.0.0.1`、`[::1]:27015`。
- `localhost`。
- 带点的域名，例如 `example.com`、`l4d2.moe:27016`。
- 带 `connect` 或 `steam://connect/` 前缀的地址。

填入的是规范化后的地址，会自动补上默认端口 `27015`。剪贴板为空、内容不符合上面这些格式（例如随手复制的单词、整段文字、网页链接）或读取失败时，输入框保持为空，也不会弹出提示。

点击“连接”或按回车会立即连接，服务器不会被加入收藏。如果需要长期使用，请改用“添加服务器”收藏；该地址已在收藏中时，直连同样会更新最近连接列表。

## 导入和导出

服务器配置可以导入或导出：

- 导出到剪贴板。
- 导出到文件。
- 从剪贴板导入。
- 从 JSON 文件导入。

导入时会跳过已存在的地址，只添加新的服务器。

## 面板高级控制

面板高级功能适合服务器管理者使用，可以更方便地查看多个服务器状态，并快速执行常用管理操作。

> 高级面板功能需要服务器端先部署面板，并在收藏服务器配置中填写面板地址和密码后才会生效。

> 面板需要使用作者的 [LaoYutang/l4d2-server-next](https://github.com/LaoYutang/l4d2-server-next) 项目搭建。配置完成后，服务器列表会显示“面板”标记，并可以打开面板详情。

面板详情支持：

- 查看在线玩家。
- 刷新面板状态。
- 重启服务器。
- 切换地图。
- 修改难度。
- 上传地图文件。
- 清空地图。
- 发送 RCON 指令。
- 在浏览器中打开面板。

这些操作会直接影响服务器，请在确认没有玩家受影响后再执行重启、清空地图等危险操作。

## 常见问题

### 服务器查询失败怎么办？

服务器查询失败可能是地址错误、服务器未开放查询端口，或本地网络无法访问。

检查项：

- 地址格式是否正确；如果填写了端口，确认端口在 `1–65535` 范围内。
- 服务器是否在线。
- 防火墙是否允许查询。
- 是否能在游戏内直接连接。

### 面板控制失败怎么办？

面板高级控制需要正确的面板地址和密码。

如果失败，请检查：

- 面板地址是否能在浏览器打开。
- 密码是否正确。
- 面板接口是否可访问。
- 服务器配置中的面板地址是否包含协议，例如 `http://`。

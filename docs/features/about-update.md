“关于”页面展示应用信息、项目链接和版本更新入口。

## 检查更新

点击“检查更新”后，应用会请求最新版本信息。

如果发现新版本，会显示：

- 当前版本。
- 最新版本。
- 更新内容。
- 下载镜像选择。

## 下载镜像

更新弹窗支持 GitHub 直连和镜像地址。可以刷新镜像延迟，也可以填写自定义镜像。

如果下载很慢或失败，可以换一个镜像再试。

## 更新注意事项

- 更新时不要手动删除正在运行的程序文件。
- 如果杀毒软件拦截下载或替换，请先确认来源再放行。
- 下载完成后显示“更新已就绪”。点击确定，程序正常退出，更新助手完成备份和替换后重新打开。
- 更新暂存及原程序备份保存在 `%APPDATA%/LytVPK/updates/update-*`，不会在安装目录创建 `.new` 或 `.old`。安装目录只读但现有 EXE 可修改时，也可更新。
- 关闭“更新已就绪”提示后可继续使用；下次自行退出时完成替换，不会强制结束程序。只有点击确定请求重启时，助手才会自动重新打开。
- 替换前校验更新文件与原程序，替换后校验结果；安装失败时保留原文件或尝试从备份回退。失败详情会在下次检查更新时显示。

## 常见问题

### 更新失败怎么办？

可以尝试：

- 更换下载镜像源。
- 关闭应用后重新启动再检查更新。
- 检查是否有杀毒软件拦截。
- 手动下载新版覆盖安装。

如果提示 `Access is denied`，需区分目录不允许新建文件和 EXE 本身不可修改。新更新器能处理前一种情况；EXE 本身只读或被安全软件占用时，请退出程序后手动覆盖，或把程序放到当前账号可修改的位置。
